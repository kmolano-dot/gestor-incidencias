## Contexto

El repositorio acababa de crearse y solo tenía un README mínimo. Antes de que el equipo empezara a subir código hacía falta acordar cómo se iba a trabajar: en qué ramas, cómo nombrar los commits y cómo revisar los aportes de los demás.

## Qué se hizo

- Se completó el `README.md` con la descripción del proyecto, las responsabilidades del equipo, las tecnologías previstas y los primeros pasos.
- Se agregó `CONTRIBUTING.md` con el flujo de ramas, commits y pull requests, el reparto de trabajo por integrante y las recomendaciones para las evidencias.
- Se agregó `.github/PULL_REQUEST_TEMPLATE.md`, la plantilla que GitHub carga al abrir un pull request.
